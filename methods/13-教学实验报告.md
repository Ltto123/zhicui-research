# 13．教学实验报告

适用：大学物理及类似的定量测量课程实验。输入：课件／指导书和真实记录；交付：符合课程要求的报告。编程、操作练习、定性观察另按目标调整；研究教学干预效果的论文使用08／09卡，不因“教学实验”字样套本卡。

1. **写什么：**说明实验要测定、检验或理解什么，实际记录能够支持怎样的回答；不要求强行宣称原创贡献。
2. **怎么组织：**目的与原理 → 仪器和实际过程 → 原始记录 → 数据处理与不确定度 → 结果讨论与结论。教师另有结构时采用其要求。
3. **怎么用证据：**原始记录与整理后数据分别保存；公式、单位、仪器条件和修正来源清楚。识别照片中影响结果的歧义，不猜读关键数字。
4. **怎么论证：**解释测量如何得到物理量、偏差来自哪里、结果与理论是否相容；使用适合该实验的误差或不确定度分析，不机械套公式。
5. **怎么呈现：**给出必要计算示例、表格、拟合和结果单位；实验过程描述实际所做内容。摘要和结论突出结果及其不确定性。
6. **交稿检查：**从记录重算关键结果，核对量纲、有效数字、图表和原理；理论值不能填入实测栏，“人为误差”不能代替具体分析。

方法依据：MIT Junior Lab 的写作材料强调主题句主线、实验关键细节、数据与误差分析以及结论的科学含义。[课程官方写作模板，2014](https://web.mit.edu/8.13/www/Samplepaper/sample-zipped/sample-paper.pdf)。这是教学规范而非顶刊论文；其页数、图数和排版不作为所有课程标准。结合用户既有课件—原始数据—报告路径制定本卡。
