# 08．教育、经济与社会定量论文

适用：问卷、实验、纵向和其他社会研究数据；按具体设计选择分析方法。交付：论文、结果表图及测量与分析说明。

1. **写什么：**说明要描述现象、预测结果，还是识别因果；把理论概念转成能由资料回答的问题。
2. **怎么组织：**问题与既有解释 → 理论和测量 → 设计与分析 → 主要发现及替代解释 → 理论和实践含义。
3. **怎么用证据：**交代样本来源、测量质量、时间顺序、分组与缺失；报告效应大小和不确定性，解释统计单位与聚类等依赖关系。
4. **怎么论证：**描述研究解释测量与代表性；预测研究检验样本外表现；因果研究说明设计与识别假设如何排除替代解释。机制推测不能自动继承主效应的证据强度。
5. **怎么呈现：**每张表回答一个问题；模型、变量口径和样本变动清楚，正文解释实质意义，不只重复显著性星号。
6. **交稿检查：**按目标启用检查。预测任务检查与应用对象一致的数据划分、防泄漏、样本外性能及适用的校准；因果任务检查识别假设和替代解释；共同检查测量、缺失和外推。观察性资料不自动支持因果。

样本观察：PNAS 教育实验分别测量实际学习和学习感受；AER 邻里研究区分获券与使用住房券的估计及额外假设。[PNAS，2019](https://www.pnas.org/doi/full/10.1073/pnas.1821936116)、[AER 作者公开版，2015](https://opportunityinsights.org/wp-content/uploads/2018/03/mto_paper.pdf)。数据与代码交付参照目标刊物要求，例如 [AEA 政策](https://www.aeaweb.org/journals/data/data-code-policy)。

这两篇是实验研究样本；预测分支是结合07卡计算方法检查提出的产品要求，不归因给这两篇论文。
