# 09．定性与混合方法论文

适用：访谈、观察、案例、过程与意义研究；混合方法同时调用相应定量卡。交付：论证完整的论文及必要分析说明。

1. **写什么：**解释行动、意义或过程如何发生，说明场景和材料为何适合回答问题；先识别所采用的定性传统。
2. **怎么组织：**问题与解释视角 → 场景、材料和分析过程 → 主题、机制或过程发现 → 与理论对话及边界。不是按受访者逐个转述。
3. **怎么用证据：**追溯原始记录、分析判断和概念；交代取样、研究者位置及分析变化，主动检查反例和矛盾材料。编码不是所有定性传统的统一必选步骤。
4. **怎么论证：**解释材料为何支持某种理解，以及竞争解释是否更好。混合研究须说明两类材料在哪里结合，不能各写一半就称整合。
5. **怎么呈现：**引文保留语境，案例选择有依据；必要的比较表或过程图帮助看清论证，不强制套一种数据结构图。
6. **交稿检查：**查脱离语境的摘引、挑选材料、概念漂移和无法追溯的判断；定量定性结果冲突时解释冲突，不删去不合意材料。

样本观察：Edmondson 的团队研究把前期访谈、量化检验和回访案例连接起来，并限制横截面设计的因果解释。[ASQ，1999，MIT 公开出版版](https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Organizational_Learning_and_Change/Edmondson_1999_Psychological_safety.pdf)。它是混合方法例子，不能代表全部纯定性研究；透明性要求按 [ASQ 投稿指南](https://journals.sagepub.com/author-instructions/ASQ)与具体方法确定。

纯定性补充：Hargadon 与 Sutton 将 IDEO 的观察、访谈、设计实物和档案连接到技术中介机制，保留单案例边界；本轮只读取方法与讨论选段，不称逐页通读。[ASQ，1997，作者上传的出版版转录](https://www.researchgate.net/publication/234021560_Technology_Brokering_and_Innovation_in_a_Product_Development_Firm)。
