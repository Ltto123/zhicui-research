# 05．临床随机试验论文

适用：已经完成的随机试验及其明确标注的后续分析。观察性研究、诊断研究、病例报告另选对应方法，不套本卡。

1. **写什么：**明确人群、干预、比较、结局与时间窗；区分主要、次要和探索性问题。
2. **怎么组织：**研究依据 → 设计与分析 → 参与者流转和结局 → 效应解释、伤害与局限。研究实际做法优先于理想模板。
3. **怎么用证据：**报告分组、样本流失与实际分析人群；二分类结局报告组别事件数、分母、绝对和相对效应及不确定性，其他结局采用适合的效应指标。缺少信息时说明，不猜算。
4. **怎么论证：**估计方向、精度与临床意义分别解释；亚组内显著不等于亚组之间有差异。阴性或不确定结果同样形成完整论文。
5. **怎么呈现：**按预设终点顺序报告结果，清楚标注方案偏离和事后分析；按目标刊物组织摘要、表图与附录。
6. **交稿检查：**核对终点层级、缺失、多重比较、效应区间及措辞；不得把包含无效值的区间写成已确定获益。

样本观察：D-Health 心血管分析报告的区间仍包含无效值，因此结论强度必须保留不确定性；该分析也不能改写成整个试验的主要终点。[BMJ，2023](https://www.bmj.com/content/381/bmj-2023-075230)。今后的报告检查对照 [CONSORT 2025](https://www.consort-spirit.org/)，不声称旧论文遵循后来版本。本卡不提供诊疗建议。
