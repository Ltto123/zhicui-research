# 01．主题与整合综述

适用：围绕概念、机制、技术或教育问题综合已有研究。交付：完整综述及真实参考文献，必要时附证据对照表。

1. **写什么：**回答一个明确问题，说明已有认识之间的关系、分歧和仍待研究的内容。先确定综述类型与边界。
2. **怎么组织：**问题与范围 → 按主题或解释框架综合 → 比较联系与分歧 → 结论回答问题。章节不能变成逐篇论文摘要拼接。
3. **怎么用证据：**记录研究对象、设计、发现和局限；比较研究质量、条件与独立性。相似结论是否来自同一批数据必须识别；没有固定的通用引用数量门槛。
4. **怎么论证：**每节解释“这些研究共同支持什么、为什么不同、判断限于何处”。由未检索到证据推断“领域完全空白”是不充分的。
5. **怎么呈现：**摘要交代问题、综合认识和贡献；采用能支持比较的表图，按目标期刊交代适当的检索与选择方法。
6. **交稿检查：**检查主线、证据支持、反例、概念一致性和结论回应；按照本次生效的用户方法检查，被替换的默认规则不再执行。

样本观察：Wang 等的 Nature 综述把论述组织为数据、表征、假设、实验／模拟及共同挑战，用跨领域案例解释方法的作用，随后讨论限制，而不是依次介绍作者。[论文：Nature，2023](https://www.cs.cornell.edu/gomes/pdf/2023_wang_nature_aisci.pdf)。本卡结合该结构与用户提供的方法归纳，不是 Nature 统一模板。
