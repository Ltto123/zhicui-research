# 12．研究方案与实验方案

适用：尚未实施的实验、观察、计算、访谈或理论研究计划。交付：独立完整的方案、资料／数据记录模板与分析安排。

1. **写什么：**明确要解决的问题、已有依据、拟检验的假设或拟解释的现象；先说明这项设计如何产生答案。
2. **怎么组织：**研究依据 → 问题和目标 → 设计与实施 → 需要记录的材料 → 分析计划 → 可行条件与局限。无需经费或商业化模块。
3. **怎么用证据：**明确研究单位、测量或资料定义、对照、样本或材料充分性依据、分析假设与偏离处理；各项按方法决定适用性，不能给访谈和数学统一套功效分析。
4. **怎么论证：**逐项连接“问题—观察或操作—记录—分析—可得判断”；预先考虑失败、缺失和替代解释。预期效应是设计假设，不是实际结果。
5. **怎么呈现：**真实实验包含步骤、条件、记录表与判断标准；定性研究包含取样与材料分析安排；计算研究包含数据和评价设计。临床试验方案另用适用规范。
6. **交稿检查：**检查问题与设计、记录与分析是否对应，现实条件是否明确；涉及人或动物时如实记录相应伦理和执行条件，不代办或虚构批准。关键条件未知时标明讨论稿与待补项，不称为可直接执行方案；现场执行后才据真实材料形成结果。

样本观察：REGAIN 方案明确连接研究终点、样本量假设和分析安排。[BMJ Open，2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5129073/)。它是临床方案样本；[SPIRIT 2025](https://www.consort-spirit.org/)只用于相应试验，不作为所有学科的通用清单。通用卡还需组合具体领域的方法。
