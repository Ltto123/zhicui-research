# 06．工程器件与系统论文

适用：材料器件、工程装置和系统设计及验证。交付：论文、性能图表和必要的设计／测试说明。

1. **写什么：**定义实际问题、工况和目标性能，解释新设计解决了什么约束或权衡。
2. **怎么组织：**需求与原理 → 设计选择 → 表征与对照 → 系统性能 → 适用条件和局限。每项设计细节都应服务于目标。
3. **怎么用证据：**性能比较统一条件与基线；分别记录实测、仿真和理论预测，报告误差、失效条件及代价。
4. **怎么论证：**连接“设计特征—物理或工程机制—可观测性能”。有性能改进不自动证明宣称的机制，实验室效果不自动成立于全部场景。
5. **怎么呈现：**提供必要结构图、条件、单位、测试方法和比较表；正文解释关键结果，附录承接复现细节。
6. **交稿检查：**核对比较公平性、模型假设、单位、重复性和外推；不能把理想条件预测写成已实测性能。

样本观察：日间辐射制冷论文用热平衡、光学表征、材料对照与冷却功率连接设计和效果；实测、理想预测和建筑估算各有边界。[Nature，2014](https://web.stanford.edu/group/fan/publication/Raman_Nature_515_540_2014.pdf)。其旧 Letter 版式不替代 [Nature 现行投稿格式](https://www.nature.com/nature/for-authors/formatting-guide)。
