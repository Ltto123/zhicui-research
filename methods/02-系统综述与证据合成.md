# 02．系统综述与证据合成

适用：系统综述、范围综述及适合进行合并分析的问题。交付：完整综述、检索筛选记录及所需证据表图。

1. **写什么：**预先界定研究问题、资料范围和纳入规则；先判断目标是描绘证据版图、解释经验，还是估计效应，不能一律做 meta 分析。
2. **怎么组织：**问题 → 检索、筛选、提取与评价方法 → 证据特征和合成结果 → 可信度、局限与结论。范围综述按范围问题和适用扩展调整。
3. **怎么用证据：**保留实际检索式、日期、筛选理由；区分一项研究和它的多篇报告。效应综述按设计评价偏倚；范围综述按目的决定是否评价并说明理由，未评价不能自动判不合格，也不能据此判断疗效确定性。
4. **怎么论证：**能否合并先看人群、测量和设计；解释异质性与敏感性分析。网络分析还需检查间接比较成立的条件；排名不等于确定最优。
5. **怎么呈现：**正文报告必要方法和结果，附筛选流程、研究特征、效应与可信度说明。没有系统检索和完整筛选，不自称系统综述。
6. **交稿检查：**核对重复样本、合并计算、排除规则和遗漏；不能用总样本量大掩盖证据质量低。

样本观察：Noetel 等的运动与抑郁网络 meta 分析分别报告效应、可信度与敏感性分析，展示三者需要分开解释。[BMJ，2024](https://www.bmj.com/content/384/bmj-2023-075847)。报告规范依据 [PRISMA 2020](https://www.prisma-statement.org/prisma-2020)及[相应扩展](https://www.prisma-statement.org/extensions)，不把健康研究评价工具直接套给所有领域。

读取范围：公开镜像相关正文；官方全文及更正未完整核验，见[阅读记录](../论文阅读记录.md)。范围综述的评价分支依据 [PRISMA-ScR 第12、16项](https://www.prisma-statement.org/s/PRISMA-ScR-Fillable-Checklist_11Sept2019.pdf)。
