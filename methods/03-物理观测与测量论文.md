# 03．物理观测与测量论文

适用：以观测、测量和物理模型解释现象的论文；化学、材料相关测量可结合领域方法细化。交付：正文、图表和可复核分析说明。

1. **写什么：**明确观测现象或待测物理量，说明什么结果支持何种解释，哪些替代解释需要排除。
2. **怎么组织：**研究问题与理论预期 → 装置和数据 → 信号、校准与检验 → 参数或机制解释 → 适用范围。短文可压缩章节，不压缩关键证据。
3. **怎么用证据：**说明测量条件、校准、对照、噪声与独立观测；保留原始记录和数据处理路径，区分随机不确定度与系统来源。
4. **怎么论证：**分开证明“信号存在”“参数是多少”“何种模型能解释”。与理论一致不等于排除所有理论，拟合好也不等于机制成立。
5. **怎么呈现：**图轴、单位、误差定义、拟合方法和参数范围完整；理论推导交代近似条件与量纲。
6. **交稿检查：**复核关键计算、单位、有效数字、噪声排查和模型依赖；摘要、正文与图表使用同一结果。

样本观察：引力波发现论文依次呈现观测、探测器验证、搜索与源解释；不同证据承担信号检出和来源归因的不同任务。[PRL，2016](https://link.aps.org/pdf/10.1103/PhysRevLett.116.061102)。历史样本页数不当作现行限制，篇幅与体例按 [PRL 作者指南](https://journals.aps.org/prl/authors)。
