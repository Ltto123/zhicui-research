# 04．生命科学实验论文

适用：细胞、生物体及其他生物机制实验；根据对象细化规范。交付：以真实实验结果为基础的论文、图表与方法附件。

1. **写什么：**围绕可检验的机制或功能命题，区分现象、干预效应和机制解释。
2. **怎么组织：**问题 → 支持核心判断的结果链 → 机制与替代解释 → 讨论与方法。结果小节按科学问题组织，不按实验完成日期排列。
3. **怎么用证据：**解释对照和干预的作用，分清生物学重复与技术重复；如实交代样本、排除、随机化、盲法及测量方式。
4. **怎么论证：**不同实验共同支持同一判断时，说明它们分别排除了什么；单一相关图不能承担因果结论，模型生物结果不能直接外推人类。
5. **怎么呈现：**每个结果主张绑定图表及比较对象，图注定义样本量和误差线；方法写清研究单位、测量定义、关键条件、对照、样本依据、分析假设和偏离处理，提供复核研究所需的信息。
6. **交稿检查：**核对实验单位、图像来源、统计与正文；缺实验时标明待验证，不生成虚构结果补链。

样本观察：IL-11 论文由年龄关联推进到遗传和药物干预，最后检验寿命；这些证据支持小鼠模型中的判断。[Nature，2024](https://www.nature.com/articles/s41586-024-07701-9)。活体动物报告适用 [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines)，不泛化为全部生命科学实验。
