# 共同原则与用户方法

本轮方法库是产品拟内置的精简写作规则，不是已经运行的 Skills。按十四类常见成果组织，再按学科、研究设计和目标刊物细化；不能据此宣称已经穷尽全部学科。具体论文的做法、期刊规定、本产品建议分别标明。

## 所有成果共用的六条原则

1. **先确定要回答的问题。** 明确最新交付目标、预期读者和已有材料。论文回答研究问题；方案解释怎样取得答案；报告解释现有数据说明了什么。遇到陌生体裁，优先从所选范文或同类文章的已读部分提炼各节的任务、论证次序和所需证据；用自己的证据写，不照搬结论、虚构期刊规则，也不强制另行检索模板。只改一个图，也先说明图要表达的判断。
2. **先列论证清单，再展开成稿。** 列出总问题、章节任务、核心主张、证据位置、论证方法、反例与边界。研究初期只有问题和拟采用方法；结论必须随着真实证据形成。用户默认看得到，系统默认继续，不增加逐条审批。
3. **证据和推理都要可追溯。** 事实对应文献或记录，计算对应输入和步骤，证明对应假设与引理，解释对应材料和推理理由。综合判断标明依据，待验证建议不得写成事实。可溯源不等于每句话都堆引用，也不意味着把模型的私有思维过程公开。
4. **每一节都推进总问题。** 常用段落关系是“主张—证据—解释—判断”，但不机械要求每段四句话。方法段解释设计为什么合适，证明段承担推导，文献回顾建立问题；不是每个小标题都必须提前写成肯定结论。
5. **把质量检查交给系统。** 自动查原文支持范围、来源独立性、反例、方法假设、结果一致性和格式；有资料时复算。工作台自身的取证比例、获取失败、资源上限和检查范围仅进用户侧折叠记录。正文据可核实的内容收窄或撤回判断，不得借一句免责声明维持无依据的结论。原研究的样本、设计与测量局限，以及真实综述协议所要求的纳排信息，仍按体裁报告。文字顺畅和多个 Agent 达成一致都不能代替证据。
6. **先看论证，后看格式。** 只读章节要点应能看出主线；只读摘要与结论应能看出问题、发现与贡献。弱证据缩小结论；必需材料缺失就说明，不用编造填满版面。成稿后渲染检查图表、公式、引用和分页。

## 2026-10-25 开工补充：有理有据的写作

写文章必须有理有据。先交代事实、证据与推理的适用条件，再形成判断；不要轻易使用“因此”“不是……而是……”等总结或强调句。使用“因此”必须存在足以支持该推论的前提；使用对比句必须有真实、必要的比较依据，不能以语气代替论证。本条同时用于生成、自动审查和定向修订。

## 两层方法，加一个独立的格式设置

| 层次 | 如何使用 |
|---|---|
| 内置方法 | 根据成果类型与研究设计选择下列卡片；跨学科可组合 |
| 用户方法 | 明确要求可补充、融合或替换对应方法；范文先提炼章法，不能抄结论或借用其中数据 |
| 格式设置 | 期刊、课程或实验室规定单独保存；只改格式不改科学判断 |

真实性、来源诚实和不夸大结论不被覆盖。先列明本次保留、覆盖和停用的方法要求，生成、审查与修订使用同一套；只有“补充”才叠加检查。科学方法冲突先检查适用条件；无法从材料判断且影响结论时集中问必要问题。格式冲突说明具体差异。某一任务的方法不会自动套到其他项目。

## 用户的综述方法：指定教育综述配置

此配置只在用户明确调用这套综述方法，或继续该项教育综述时启用。同一项目中新建不同主题的任务，也不自动继承四个题目和三项证据门槛。

- 全文围绕明确研究问题，按“提出问题—分主题综合—讨论联系—回答问题”推进；教育理论承担解释作用。
- 每节采用“明确论点—相关证据—比较与解释—形成判断”；结论逐项回答问题。该教育综述的四个问题为：如何分工、备课负担、教学设计质量、教师决策。
- **每个核心论点至少三项相关研究证据**，同时检查研究质量、独立性和适用条件。这是本项目约定，不是所有综述或学科的统一规定；不足时补查或收缩主张，不凑数。
- 比较贡献、共性、差异与条件；重要空白集中讨论。核实身份和引用内容；摘要证据不超范围，预印本不冒充正式发表。
- 区分已有研究发现、本文综合判断和待验证建议；相关不写成因果。使用清楚的陈述句，少用刻意对立和空泛概念。
- 正文写学术内容。按体裁报告确实采用的检索、纳排与综合方法；工作台自身的检索或读取困难、取证比例与协作进度只记入侧栏。若因此缺少某项论据，收窄或撤回具体主张。
- 交稿先查主线与证据，再检查语言、引用和逐页排版。

## 项目默认底稿

| 项目 | 默认值 |
|---|---|
| 页面 | A4；四边页边距2.54厘米 |
| 字体 | 中文宋体；外文和数字 Times New Roman |
| 正文 | 10.5磅；1.5倍行距；两端对齐；首行缩进2字符；段前段后0 |
| 标题 | 主标题18磅；一级12磅；二级10.5磅；层级可加粗 |
| 摘要、关键词、参考文献 | 9磅；参考文献悬挂缩进 |
| 参考文献 | 本项目选 GB/T 7714—2025 顺序编码；按首次出现顺序编号，重复引用沿用原编号；不猜补书目信息 |

这些字体和页面设置是项目约定，不统称国标。国家标准平台确认 GB/T 7714—2025 于2026年7月1日实施；本轮核验了状态和日期，未据此声称逐条核验完整标准文本。目标刊物另有要求时按其适用规范处理。[官方标准记录](https://std.samr.gov.cn/gb/search/gbDetailed?id=w3O2P1Odh2Q%3D&mode=p)

期刊专属的 AI 使用说明随成果生成，准确记载实际用途，具体按目标刊物要求。例如 Annals 要求说明 AI 贡献的想法及其在文中的位置；这不是要求用户逐字审校。[Annals 投稿指南](https://annals.math.princeton.edu/submission-guidelines)

后续卡片中的“检查”都是拟内置的产品要求，尚未完成能力验证。分别记录读取范围与支持判断：全文／摘要／原始记录／汇总结果等属于前者；支持／部分支持／不支持／相互矛盾／无法判断属于后者。完成核对不等于获得支持；未核验或遭反驳的主张不能作为确定事实成稿。系统自行补查、改写或限制结论，不要求用户逐条核对。
