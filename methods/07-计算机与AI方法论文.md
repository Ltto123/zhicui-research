# 07．计算机与 AI 方法论文

适用：算法、模型和计算方法研究。理论主张走数学证明路径，经验主张走实验路径，混合论文分别匹配。交付论文及与主张对应的证明或实验材料；纯理论论文不要求补经验实验。

1. **写什么：**说明现有方法的具体限制、新方法改变了什么、为什么值得研究。
2. **怎么组织：**问题与相关工作 → 方法原理 → 对应验证 → 局限。经验研究安排评价、比较和适当的消融；理论研究安排假设、命题和证明。章节围绕贡献，不围绕代码模块。
3. **怎么用证据：**经验研究说明数据划分、指标、基线、调参条件、随机性和计算代价；理论研究说明假设与推导，不要求数据划分或训练结果。
4. **怎么论证：**实验比较回答是否有用，消融分析组成作用，稳健性检验适用条件；理论结论由有效证明支持。性能表不能独自证明机制，理论界也不自动证明实际效果。
5. **怎么呈现：**方法定义清楚，图表能被复核，附必要参数和复现条件；负面结果与失败案例也应支持适用边界。
6. **交稿检查：**经验路径查数据泄漏、基线公平、调参、选择性报告和数字差异；理论路径采用11卡的证明检查。未跑过的实验、未核验的证明分别保留真实状态。

样本观察：Dropout 论文把模型、训练、实验和特性分析分开，讨论不同数据量及方法比较中的限制。[JMLR，2014](https://www.jmlr.org/papers/volume15/srivastava14a/srivastava14a.pdf)。JMLR 明确要求主张有实验或理论支持、报告实验可复现；这不等于所有方法必须采用同一套消融项目。[官方要求](https://www.jmlr.org/author-info.html)
